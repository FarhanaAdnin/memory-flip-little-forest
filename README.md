# 🐻 Memory Flip — Little Forest

A cute, animal-themed memory matching game built using **HTML, CSS, and JavaScript**. Players flip cards to find matching animal pairs while tracking their moves and completion time.

The game features a soft pastel-green design, interactive card animations, and playful sound effects for a fun and relaxing experience.

## 🎮 Features

- **Three Difficulty Levels:** Easy (6 pairs), Medium (8 pairs), and Hard (10 pairs).
- **Card Matching:** Flip two cards at a time to find matching animal pairs.
- **Move Counter:** Tracks the number of attempts made.
- **Optional Timer:** Measures how long it takes to complete the game.
- **Sound Effects:** Different sounds for flipping cards, correct matches, incorrect matches, and winning.
- **Sound Toggle:** Players can enable or disable sound effects.
- **Star Rating:** Awards 1–3 stars based on the number of moves.
- **Restart Game:** Start a new game with randomly shuffled cards.
- **Responsive Design:** Supports desktop, tablet, and mobile screen sizes.

## 🛠️ Technologies Used

- **HTML5** — Game structure and interface
- **CSS3** — Styling, responsive layout, and card-flip animations
- **JavaScript (Vanilla JS)** — Game logic, card shuffling, timer, and score tracking
- **Web Audio API** — Interactive sound effects

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/FarhanaAdnin/memory-flip-little-forest.git
   ```

2. Open the project folder.

3. Open `index.html` in a web browser, or use the Live Server extension in VS Code.

No additional libraries or installation are required.

## 🕹️ How to Play

1. Select a difficulty level.
2. Click a card to reveal an animal.
3. Flip another card to find its matching pair.
4. If the cards match, they remain revealed.
5. If they do not match, they flip back.
6. Match all pairs to complete the game and earn your star rating.
